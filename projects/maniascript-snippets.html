ManiaScript Snippets

PreviousNext

Description

ManiaScript Snippets (MSSnippets) is a Visual Studio Code extension that adds code snippets for ManiaScript, the scripting language used to build Trackmania's UI, ManiaLink interfaces, and game modes.

It speeds up writing the repetitive patterns that come up constantly when working in ManiaScript — loops, conditionals, control declarations, and event handlers — so you can drop in a working skeleton straight from the editor instead of typing it out from scratch every time.
